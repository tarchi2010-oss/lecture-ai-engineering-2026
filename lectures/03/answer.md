# 第3回 解答
## 演習
- 第1回（素のLLM）とエージェントの回答の違い：第1回はLLMが自分の知識だけで直接答えた。第3回のエージェントは、答える前に用語集を検索し、その定義に基づいて回答し、関係する回（第N回）を明示した。質問の種類に応じて、使う道具（用語検索・回の要点・問題作成）を使い分けていた。
- `--trace` で見えたツール呼び出し（ツール名と引数）：search_glossary({'query': 'LoRA'})、make_quiz({'lecture': 2})
- 1つの質問での LLM 呼び出し回数（`requests`）：2回（1回目でツールの呼び出しを決め、結果を受けて2回目で回答を作る）
- 追加したツールと、docstring に書いた説明：make_quiz。「指定した回の用語から、確認問題を1問作る。「第N回の問題を出して」のように言われたときに使う。戻り値は {"question": ..., "answer": ...} の JSON 文字列。」用語集から指定した回の用語を1つ選び、定義を問題文にして返すようにした。
## 宿題
- 取り組んだレベル：基礎
- やったこと：app/agent.py の INSTRUCTIONS から「用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する。」の1行を削除し、変更前と同じコマンド `uv run python -m app.agent --trace "LoRAって何ですか？"` を実行して比べた。
